02 / Get running

Installing and first launch

Download the build for your platform from the Releases page. There is no account and no setup wizard. Xpecter opens on the Home tab.

Windows

Run xpecter-windows-installer.exe, or unzip the portable build. Windows 10 1809 or newer is required for local shells.

macOS

Unzip and run the app. Because the build is not signed yet, right-click and choose Open on first launch.

Linux

Extract xpecter-linux-amd64.tar.gz and run the xpecter binary. No install step is needed.

Upgrading from Specter: the old specter configuration directory is migrated automatically.

03 / Orientation

The window

Xpecter draws its own title bar, menus, theme toggle, and window controls. The Home tab is permanent; every other tab contains an independent pane layout.

Tabs and panes

Tabs can hold SSH, shells, serial consoles, Remote Desktop, VNC, or editors. Split vertically, horizontally, or into a four-pane grid. Drag dividers to resize. Drag a pane header onto another pane to swap them.

The sidebar

Sessions, Local shells, Folders, and Remote files are collapsible sections. Drag its edge to resize it, or press Ctrl + Shift + B to hide it.

Home

Home combines Quick connect, pinned and recent sessions, saved sessions grouped by folder, local shell profiles, and current shortcut bindings.

04 / First connection

Your first connection

  1. Open Sessions > New Session, the + New Session button, or press + in the Sessions sidebar.
  2. Choose SSH, then enter the host and user. Pick Password or Key authentication.
  3. Click Connect. On first contact, verify the host fingerprint and choose Trust and connect.

The fingerprint is checked against your own ~/.ssh/known_hosts, the same file used by OpenSSH. Passwords are never saved unless you enable OS keychain storage.

05 / Connections

Session types

SSH

Keys, passwords, agents, X11 forwarding, jump hosts, keepalive, and legacy hardware compatibility.

Shell

Your local login shell, with named profiles and starting directories.

Serial

Console over COM or tty ports, from 9600 to 115200 baud.

Telnet

Legacy unencrypted equipment through your system's telnet client.

Remote Desktop

Launches the platform client with a generated RDP file. Xpecter tracks the pane.

VNC

Opens the installed platform viewer and tracks it as a session card.

Mosh

Start it from Terminal > New Mosh Session. The local mosh client and remote mosh-server must be installed.

06 / Organization

Saved sessions and the sidebar

Saved sessions can be pinned, grouped into nested folders, tagged, filtered, and opened with one click. Right-click a session to pin, open another copy, edit, forget a saved password, or delete it.

Import

Settings can import .mxtsessions and .ini files from MobaXterm, or concrete host blocks from OpenSSH config. Passwords and wildcard-only rules are skipped.

Local shells and folders

Shell profiles appear in the sidebar, Home, and Terminal menu. Pinned workspace folders open in the editor and stay visible as you move between sessions.

07 / Daily work

Working in the terminal

Terminal output can highlight outcomes, interfaces, addresses, log tags, URLs, paths, timestamps, rates, and sizes without disturbing text that arrived pre-colored. URLs require Ctrl-click to open.

Paste safely

Right-click paste is enabled by default. Multi-line paste translates line endings and uses bracketed paste where supported. Network equipment can prompt before lines run one at a time. OSC 52 clipboard writes are off by default.

Scrollback and logging

Scrollback defaults to 10,000 lines and can reach 100,000. Session logging appends raw output to a directory you choose in Settings.

When a session drops: the pane stays in place. Press R to reconnect, S to save output, or Enter to close it.

08 / Build and edit

The editor

The editor can fill a tab or sit beside a shell. Open files from a local workspace tree or over SFTP. Each pane owns its documents and responds to Save only when it has focus.

Files and workspaces

Create, rename, delete, and refresh files from the tree. Open documents follow a rename. Unsaved buffers survive deletion. Folder changes are watched while visible.

09 / Remote files

Remote files over SFTP

With an SSH session focused, Remote files browses that host's filesystem. Navigate folders, open files in the editor, create, rename, delete, and upload by dragging from your desktop. Saving an opened file writes it back over SFTP.

Remote download by drag-and-drop is not available yet. Open the file and use Save As locally, or Shift-click it to open a temporary copy in the system application.

10 / Utilities

Tools

Port forwarding

Create local -L forwards through a live SSH session. Remote and dynamic SOCKS forwarding are not available yet.

Wake-on-LAN

Send a magic packet to a MAC address and optional broadcast address.

Port scan

Scan TCP ports such as 22,80,443,8000-8100 without opening a session.

Command snippets save named commands or configuration blocks and type them into the focused session through the same paste guard.

11 / Make it yours

Appearance

Settings controls the application theme, terminal color scheme, font, font size, terminal wallpaper, and editor wallpaper. Wallpaper opacity ranges from 0 to 60 percent; terminal wallpaper uses the canvas renderer instead of WebGL.

14 / Trust boundaries

Security

Host keys are checked against your own known hosts file. Changed keys receive a stronger warning. Passwords stay out of session profiles and configuration exports. If enabled, OS keychain storage uses Windows Credential Manager, macOS Keychain, or Linux Secret Service under Xpecter.

Private keys and passphrases are not saved in session profiles. The memory agent holds unlocked keys only for the current app run. Executables opened from a file tree always ask first.

15 / Know before you go

Limitations and things to know

  • macOS builds are unsigned, and the first launch needs right-click > Open.
  • Serial ports are entered manually; detected ports are not listed yet.
  • Telnet, Mosh, X11, Remote Desktop, and VNC depend on software installed locally.
  • Port forwarding is local-only. Remote and SOCKS forwarding are planned.
  • Remote browser download by drag-and-drop is not available yet.
  • Tabs cannot currently be dragged between separate windows.
16 / Keep improving it

Reporting problems

Open an issue on GitHub with your platform, Xpecter version, session type, and what happened. A useful report can be as simple as “this crashed” or “I wish X worked like Y.”
